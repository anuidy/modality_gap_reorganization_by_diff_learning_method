# 项目结构初始化改动日志

## 1. 改动类型

- 数据：建立数据、split、metadata 与输出目录的边界。
- 模型：建立四模型 adapter 的预留目录。
- 脚本：建立数据、训练、评估、分析脚本目录。
- 配置：建立模型、训练、评估配置目录，并添加 Git 忽略规则。

## 2. 改动位置

- `configs/models/`、`configs/training/`、`configs/evaluation/`
- `data/raw/`、`data/splits/`、`data/metadata/`
- `src/datasets/`、`src/models/`、`src/objectives/`、`src/training/`、`src/embeddings/`、`src/metrics/`、`src/utils/`
- `scripts/`、`experiments/`、`analysis/`、`figures/`、`tests/`、`outputs/`
- `.gitignore`

## 3. 改动逻辑

目录按 `Dataset → Model Adapter → Objective → Embedding → Metrics → Analysis` 分层，避免为 Standard/Mixed 或单个模型分别复制训练与分析代码。`data/raw/`、`outputs/`、checkpoint 与运行缓存被排除在 Git 之外。

## 4. 改动效果

项目具备可扩展的实验骨架；后续模型、数据、指标和训练流程可放入明确位置。此改动不包含任何模型实现、训练逻辑或实验结果。
